# MagicGen (web app)

Source for the MagicGen site. Production: [https://magicgen.igottic.com](https://magicgen.igottic.com) (GitHub Pages).

## Develop

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

Deploy is handled by the root workflow `.github/workflows/deploy-pages.yml` on push to `main`.
